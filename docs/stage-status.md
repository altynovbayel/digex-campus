## Этап 3Б: что реализовано

- Один тест на урок, вопросы с 4 непустыми вариантами и одним правильным, 1 балл за верный ответ.
- Ученик получает тест без правильных ответов (`get_quiz`); баллы считает только база (`submit_quiz_attempt`):
  проверка доступа, публикации, версии теста, принадлежности и полноты ответов; повтор запроса не создаёт дубль.
- Попытка хранит снимок вопросов и ответов: правка теста не меняет прежние результаты. Ученик читает свою историю
  (баллы и проценты), но не снимок `answers` с ключами ответов; администратор — через `admin_attempt_answers`.
- Показатели (`my_quiz_stats`): пройдено тестов, попыток, средний результат (по последней попытке каждого теста),
  прогресс по опубликованным тестам.
- Администратор: редактор тестов («Разделы и уроки» → «Тест») — только через функции базы с единым порядком
  блокировок и проверкой версии; «Результаты» с фильтрами по ученику, разделу и уроку.

## Известные ограничения

- **Взаимные блокировки при перестановке уроков** (принято владельцем, не исправляется): возможны при двух
  одновременных перестановках уроков раздела во время добавления урока в этот раздел, а также при обновлении
  нескольких уроков одним прямым запросом к API. PostgreSQL прерывает одну операцию (`40P01`), данные не портятся.
- Конкурентные сценарии проверены анализом кода и ревью, а не параллельными транзакциями (PGlite — одно соединение).
